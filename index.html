Where I build

Work

Nobin

Embedded / ML Systems Engineer · Oct 2024 to Nov 2026

Noban is an assistant for elderly and disabled people that calls for help when something goes wrong. I am the sole engineer and built the device, the Android app and the server. Fall detection, the wake word, distress sounds and voice commands all run on a Raspberry Pi. The server only signals and relays: calls, push, and encrypted voice notes and clips it cannot read.

Peekage

Applied AI Scientist · Feb 2026 to Feb 2027

PeekAI answers campaign managers' questions from live data. I rebuilt its core as one tool-using agent where code computes every number and the model cannot type its own. Peek Design is a chat that builds a survey step by step. I built its Audience and Context agents and the coordinator that routes each message across five steps. I was the main developer of the AI layer: the agent harnesses, graph RAG, document RAG, RAG over survey subjects and questions, comment theme mining, on-demand skills, sandboxed tools and a large eval harness.

12 → 2model calls for a chart turn
110 → 66files in the PeekAI core
5chat steps, one coordinator
