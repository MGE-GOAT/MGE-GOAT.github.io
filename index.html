Noban

Nobin · Oct 2024 to Nov 2026

An assistant for elderly and disabled people that calls for help when something goes wrong. I am the sole engineer and built the device, the Android app and the server. Fall detection, the wake word, distress sounds and voice commands all run on a Raspberry Pi. The server only signals and relays: calls, push, and encrypted voice notes and clips it cannot read.

Applied AI Scientist · Feb 2026 to Feb 2027

PeekAI answers campaign managers' questions from live data. I rebuilt its core as one tool-using agent where code computes every number and the model cannot type its own. Peek Design is a chat that builds a survey step by step. I built its Audience and Context agents and the coordinator that routes each message across five steps.
